# 🦞 Legacy Lopez Lobster - Quantum Simulation

An interactive web application that demonstrates quantum computing concepts through the journey of a time-traveling lobster emoji! 🦞⚛️

## 🎯 What This Simulates

This application visualizes two fundamental concepts from quantum computing:

### ⚛️ Superposition
- A quantum bit (qubit) exists in a state that is a combination of both |0⟩ and |1⟩ simultaneously
- The lobster exists in multiple states at once until observed
- Represented visually with pulsing animations showing both possible states

### 🧲 Measurement (Collapse)
- The act of measurement forces the quantum state to collapse into a definite outcome
- Once measured, the lobster's fate is determined:
  - **State |1⟩**: Found in the Ocean 🌊 (Location 1)
  - **State |0⟩**: Found on a Dinner Plate 🍽️ (Location 0)

## 🌐 How to Deploy to GitHub Pages

1. Push all files to your GitHub repository
2. Go to repository **Settings** → **Pages**
3. Under **Source**, select the `main` branch
4. Click **Save**
5. Your site will be live at `https://<username>.github.io/<repo-name>/`

## 💻 Local Development

To run locally:

```bash
# Using Python 3
python -m http.server 8000

# Using Node.js
npx serve

# Using PHP
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.
