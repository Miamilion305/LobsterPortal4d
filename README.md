# 🦞 Lobster Portal 4D

A GitHub Pages site that embeds and displays a Google My Maps project with links to view in Google Earth.

## 🌐 Live Site

Once GitHub Pages is enabled, the site will be available at:
`https://miamilion305.github.io/LobsterPortal4d/`

## 🚀 Enabling GitHub Pages

To enable GitHub Pages for this repository:

1. Go to your repository settings
2. Navigate to the "Pages" section in the left sidebar
3. Under "Source", select the branch: `copilot/fork-google-earth-links` (or `main` after merging)
4. Select the root folder `/` as the source
5. Click "Save"
6. Wait a few minutes for the site to deploy

Your site will be live shortly after!

## 📍 About the Map

This site embeds a Google My Maps project that can also be viewed in Google Earth for an enhanced 3D experience.

- **Embedded Map**: Interactive map viewer directly on the page
- **Google Earth Link**: Opens the same project in Google Earth web interface

## 🛠️ Technical Details

- **Framework**: Pure HTML, CSS (no build process required)
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Accessibility**: Includes ARIA labels and semantic HTML
- **Security**: Uses proper embed parameters and security headers
